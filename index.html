Engineering decisions

The hard work was deciding what the system is allowed to claim.

The production history records a shift from feature breadth toward honest geometry, observable failure modes, and a review trail that distinguishes measurement from inference.

Selected authored work / Keenan

Keep measurement and inference separate.

Coordinate provenance travels with the result. Measured wall-local positions, approximate image-relative locations, and unreferenced detections cannot silently collapse into one confidence claim. 

position_basis
  measured        → wall-local frame
  approximate     → image-relative only
  unreferenced    → no position claim

Selected authored work / Caleb

Make the record usable beyond the scan.

The workflow became a full product surface: durable room identity, guarded uploads, workspace access, 2D review, controlled sharing, quotas, and field-facing iOS feedback. 

record_lifecycle
  capture → upload → workspace
  review  → share  → return

  boundaries: auth / rate / quota

Shared product discipline

Treat a plausible picture as the beginning of validation, not the end.

Synthetic tests verify software behavior. They are not field evidence. Hardline's validation contract requires physical ground truth before any measured accuracy claim.
