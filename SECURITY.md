# Security policy

This is a static portfolio repository with no authentication, backend, production credentials, or customer data.

If you find a concern that could expose non-public Hardline information, do not include sensitive details in a public issue. Use [GitHub's private vulnerability-reporting form](https://github.com/keenanfrancisco/hardline-engineering-showcase/security/advisories/new).

For ordinary bugs in this showcase, a public GitHub issue is appropriate.
